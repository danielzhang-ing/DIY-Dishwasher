# DIY-Dishwasher

By Sophie Barrowman and Daniel Zhang

Welcome to the GitHub Repository of our project, where we made a dishwasher from scratch and off the shelf components!

The purpose of this page is to organize, publish, and share our methodology, findings, and hopefully provide some kind of a base/foundation for anyone wanting to attempt a future related project.


This repo contains the brainstorming, research, SOLIDWORKS CAD files, Arduino code, and some other things and thoughts that this project spurred the creation of.

Further writing will be in the wiki.
